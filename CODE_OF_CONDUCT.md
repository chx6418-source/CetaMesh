# Code of Conduct

## Our standard

CetaMesh aims to maintain a technical community where people can contribute, ask questions, review code, and disagree constructively.

Expected behavior includes focusing criticism on code, design, evidence, and outcomes rather than people; welcoming contributors with different experience levels and backgrounds; giving actionable review feedback; respecting privacy and security boundaries; and avoiding harassment, threats, discrimination, personal attacks, deliberate disruption, or publication of another person's private information without permission.

## Project spaces

This standard applies to project-managed spaces including issues, pull requests, discussions, code review, and other official CetaMesh collaboration channels.

## Moderation

Maintainers may edit, hide, lock, or remove content and may restrict participation when behavior repeatedly or seriously disrupts the project or harms other participants. Moderation decisions should be based on behavior in project spaces, not unrelated personal disagreements.

## Reporting conduct problems

For ordinary moderation concerns, contact project maintainers through an available private GitHub channel when possible. Do not use a public thread to disclose private personal information.

For security vulnerabilities, use SECURITY.md instead.

## Attribution

This is a lightweight project-specific conduct policy rather than a verbatim adoption of an external code-of-conduct template.
