# CetaMesh 项目说明

CetaMesh 是一个连接不同 AI Agent、任务、记忆、插件与设备的本地优先智能协作网络。桌面端是主项目，移动端位于 apps/mobile/，两端独立运行、构建和发布，并以授权和安全隔离为跨端协作的前提。

项目目前仍处于开发与测试阶段。部分功能、原生设备验收和外部服务集成仍需进一步完善。
