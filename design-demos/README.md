# design-demos · QQ 桥接控制台 UI · 软糖拟物 × 糖果玻璃 融合专项

> 方向已收敛：废弃此前其余 8 套风格，仅保留「软糖拟物」「糖果玻璃」为基因来源，
> 基于两者的融合方向产出 **5 套不同色彩配比** 的方案（每套含 亮/暗/护眼 3 主题）。

## 融合配方（两套风格核心特征 100% 保留）

**软糖拟物 = 质感基底**
- 按钮 / 功能卡片双层分层光影：底部浅浮雕投影 + 反向柔光层
- 所有组件边缘带柔化高光（inset 顶部高光 + 底部暗缘）
- 超大圆角体系：卡片 26px / 控件 16px / 胶囊 999px，圆润饱满
- 可点击控件按压微缩 + 弹簧曲线回弹，还原实体按键手感
- 输入框 / 分段控件槽 / 开关轨道内凹、旋钮浮起

**糖果玻璃 = 全局叠加**
- 全页马卡龙渐变画布 + 柔焦糖光斑（每套配比不同）
- 侧边栏 / 顶栏 / 层级卡片半透毛玻璃（blur + saturate）
- 全链路低饱和糖果配色，accent 双色渐变、过渡自然柔化

## 预览

## 目录结构

```
design-demos/
├── index.html            # 融合方案选型页（含特征对照表）
├── fusion-1..5-*.html    # 5 套融合 Demo（自包含，可直接打开）
├── ref-*.html            # 2 套原始参考
└── src/
    ├── build.mjs         # node design-demos/src/build.mjs
    ├── serve.mjs         # 本地预览服务器（可选）
    ├── template.html     # 共享骨架（四模块 + 抽屉 + 命令面板 + Toast）
    ├── data.js           # Mock 数据
    ├── app.js            # 共享交互层
    └── css/
        ├── fusion-base.css   # 融合基底（软糖质感 + 糖果玻璃叠加）
        ├── fusion-*.css      # 各方案色彩配比（token 层）
        └── 06/10-*.css       # 原始参考皮肤
```

改配色 → `src/css/fusion-*.css`；改结构/交互 → `template.html` / `app.js`，然后 `node src/build.mjs`。
