# CetaMesh Desktop UI/UX 产品化探索（方案 01–05）

> 2026-10-10 · 上线前 UI 探索稿。**不改动生产 UI**（`desktop-shell/` 未动）。
> 目的：给 Owner 提供 5 套**信息架构明显不同**的完整方案，供人工挑选 2–3 套后再深化。

## 怎么看

- 打开 `index.html`（总览 + 每套首屏截图 + 入口）。
- 每套 `p01.html` … `p05.html` 是自包含 HTML mock，hash 路由切换 9 个视图：
  `#/home`（Chat 空状态）`#/thread`（会话线程）`#/work` `#/memory` `#/agents`
  `#/plugins` `#/plugin`（插件二级）`#/settings` `#/about`。
- 全量截图在 `screenshots/`（1280×800，5×9=45 张，命名 `p0X-视图.png`）。
- 重新生成截图：`node tools/shot.mjs`（需 `npm i playwright` + chromium）。

## 统一约定（五套共同遵守）

- **Chat 是第一入口**：首屏只有问候 + 能力表达 + Composer；Provider / Model / Reasoning
  不进首屏主视觉（只收在 Composer 右下小字或设置高级区）。
- **能力四概念**：「直接回答 · 使用工具 · 创建任务 · 交给 Agent」五套均以不同形式出现在首页。
- **导航收敛**：对话 / 工作 / 记忆 / 智能体 / 插件 + 设置·关于（生产壳现有 15 个一级项 → 5+2）。
- **Composer 附近只保留**：+（附件）、工具、Agent、模式（自动），保持简洁。
- **会话线程内表达四状态**：工具（过程步骤/时间线/胶囊）、Agent（运行中卡片/胶囊行）、
  任务（已创建任务行 → 工作页）、附件（文件纸片）。
- **插件二级设置独立入口**（二三十个工具不占一级页）：01 整页 / 02 主从详情 / 03 模态 / 04 整页分组 / 05 覆盖层。
- **智能体卡片覆盖四状态**：DSH=就绪、Codex=需要设置、ZCode=未安装、SnowLuma Host=暂不可用。
- **About/Feedback 自然可发现**：01 侧栏底部、02 图标栏 ⓘ、03 设置与头像菜单、04 用户卡弹层、05 Dock「关于」；
  反馈一律是「系统浏览器打开官网页面」的入口，不做软件内表单（与 `bf12184` 的产品决定一致）。
