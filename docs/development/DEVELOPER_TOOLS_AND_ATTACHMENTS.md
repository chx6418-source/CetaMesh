# Workspace 开发工具与 Chat 附件

这些源码功能需要相应版本的 Desktop/Core。Git 源码更新不会自动升级已安装程序；Windows Release 安全门槛独立保留。

## Git 与开发工具

Tasks 页的“Git 项目管理”读取真实状态、Diff、分支、历史、冲突和 Task 关联。普通目录仍可作为 Workspace 使用。分支/Worktree 需要关联同 Workspace 的 Task，并绑定核对后的 HEAD；Worktree 位于 StateDir 下，复用 Workspace registry，不覆盖原项目。Commit 仅包含审核的路径、内容 SHA-256 和 HEAD，保留其他暂存/未暂存/未跟踪修改。写入先进入现有 Approval，在任务审批面板批准后执行。没有自动 push、merge、force、reset、clean 或删除 Worktree 的入口。

Plugin Center 的 GitHub/GitCode 面板连接固定官方 API。公开只读连接不发送凭据；认证连接使用面板中的专用 Token 输入，密钥进入既有本机 SecretStore，配置仅保存引用。Token 和仓库范围变化会使旧审批失效。仓库、分支、Issue、PR、构建、Release 分别适配；写入要求 Task/Workspace、稳定操作身份和 Owner 审批。网络错误/取消不证明服务端未执行，未知写入不能直接重放。GitCode 工作流派发和未发布 Release 草稿明确不支持，不以预发行代替草稿。

文件、搜索、构建测试复用 Workspace 执行器。进程能力只运行 Owner 允许的固定程序/参数；诊断输出有界且脱敏。Edge 执行器使用独立 profile、固定导航与 DOM 提取，禁用页面脚本，支持取消/超时/自有进程回收；这不是 OS 网络沙箱，也不支持依赖 JavaScript 的完整网站交互。截图字节不进入普通工具文本，视觉传递仍需受控多模态入口。

## 附件

支持文件选择、图片粘贴/拖放、缩略图、预览、移除和失败重试。文件按最多 128 KiB 分块写入既有 Chat 附件目录，消息 IPC 只带随机引用。分块重试检查偏移和内容，完整文件带 SHA-256 与分块校验；拒绝跨会话、越界和链接读取。

“设置 → 附件与存储”可调整限额，单位 MiB：图片 20、文档/源码 100、ZIP 200、单消息总量 250、单消息 20 个、本地配额 2048、磁盘保留 256，未完成上传保留 24 小时。写入检查真实磁盘空间；完整附件不会被旧的会话累计字符上限截断。已上传未提交附件可恢复，历史引用随消息保存；明确删除后相应重试会报告不可用。删除会话回收其自有附件；过期未完成上传有独立清理入口。

JPG/PNG/WebP 在解码前核对类型、尺寸和像素预算；Core 再检查模型 PNG 的 CRC、解压大小和编码。原图留在本机，处理图最长边 2048、单图最多 2 MiB、合计 4 MiB，保留质量信息。DeepSeek Flash 的已核对视觉模式保留处理图细节；其他 Provider 按明确型号能力判断，未知时拒绝。图片通过结构化多模态内容块发送，不拼进普通文本 Prompt。当前 `deepseek-flash` 支持视觉，其他型号独立判断，见[官方说明](https://api-docs.deepseek.com/guides/vision/)。外部 Agent 尚无获授权附件桥时明确拒绝，不默默外传图片。

文本模型只读取有界摘录，原文件留在本机；Task 交接仅带引用清单，后续正文读取重新核验 Task、Workspace 与已提交会话归属。PDF/Office 当前支持保存和本地预览/下载，尚无通用全文提取/原生模型文档投递，不能声称读完。附件不自动写入长期记忆。

ZIP 导入先审批，再流式展开到新的受管 Workspace。检查文件范围/CRC/数量/膨胀比/总量，拒绝穿越、链接、受保护路径及重复路径；取消只清理本次自有临时目录。运行导入代码需要独立授权。

## 仿生聊天

插件开关、策略进程、QQ 账号、DSH Session/人格和 MCP 成功回执分开显示。无当前账号和白名单会话的真实工具证据时不显示 ready；首次启动可处于等待验证的降级状态。健康检查/启动/停止/安全重连复用 Channel 生命周期。

官方 `whale-chat-v2` 模板使用 `persona.config.prefix`。既有官方模板仅在所有权哈希吻合时按原升级机制更新；用户修改/未知模板和社交数据保留。真实收发仍需已登录网关、在线 DSH 和允许名单，不以 Fixture 替代账号验收。
