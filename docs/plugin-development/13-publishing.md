# 13 Publishing

The desktop is prepared to use the CetaMesh Plugin Service for Catalog metadata and package downloads. Its official root and publishing API are pending; no third-party mirror is used as a fallback.

Catalog metadata binds id, publisher, version, compatibility, permissions, capabilities, package URL, byte count, and SHA-256. The verified field is display metadata here, not proof of a cryptographic signature. Publisher onboarding, signatures, and server-side review/revocation require the official service contract.
