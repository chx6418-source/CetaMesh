# M3 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** Device identity and explicit secure pairing in the independent mobile app.
**Architecture:** Feature → Runtime/policy → domain ports → native/data/network.
**Tech Stack:** RN New Architecture, TypeScript, Kotlin, Swift, SQLite.
**Spec:** docs/superpowers/specs/2026-09-30-m3-pairing.md

## Global constraints
Private keys cannot be exported; QR token <=5 minutes; no memory upload or sync;
no Desktop writes; native failure never silently replaced with software key export.

## Review focus
Concurrent identity initialization, stale pairing confirmation, replay after restart,
malformed/unbounded QR/network input, trust deletion while an operation is pending.
